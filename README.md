# cyber-portfolio

Personal portfolio for Sros Socheata, built with Vue 3, TypeScript, Vite, and Tailwind CSS.
It presents cybersecurity skills, projects, lab work, learning roadmap, and contact links.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
